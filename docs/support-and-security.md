# Support and Security Contacts

## Public support

Current public support path:
- repository issue tracker: `https://github.com/priyanshuchawda/smart-crowd-navigator/issues`

Recommended response posture for the current deployment:
- acknowledge product/support issues as soon as practical
- keep public issue replies suitable for a public tracker
- move sensitive follow-up into a private channel before sharing secrets, tokens, or personal data

## Security reporting

For security concerns:
1. open a repository issue requesting a private security handoff
2. do **not** include secrets, tokens, credentials, or exploit details in the public issue
3. once a private channel is arranged, share reproduction steps and affected surfaces there

Preferred public subject line:
- `Security report: Smart Crowd Navigator`

## Operational ownership

Current operational owner:
- the deployment operator of the Cloud Run service `smart-crowd-navigator`

Current deployment reference:
- `https://smart-crowd-navigator-6onqsv3h4a-uc.a.run.app`

## Recommended launch links

Keep visible links to:
- Privacy Policy
- Terms of Use
- Support / Security Contact page

## Disclosure workflow

1. acknowledge the report
2. assess severity and affected surfaces
3. mitigate / roll back if needed
4. communicate status to impacted stakeholders
5. record post-incident notes when appropriate
